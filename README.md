# VR Zombie Shooter - CS 357 Project 2

A Unity 6 VR zombie shooter built with the XR Interaction Toolkit.

## Controls

- Use the XR Interaction Simulator in the Unity Editor to move the controllers.
- Grab the rifle with either controller.
- Use the trigger input to fire at zombies.

## Opening the project

1. Open this folder with Unity Hub using Unity 6.3 LTS (6000.3.23f1) or a compatible Unity 6 LTS version.
2. Open `Assets/Scenes/VRROBOTSHOOTER.unity`.
3. Press Play to test with the XR Interaction Simulator.

The project includes the source assets, packages, and project settings needed to open it. Unity-generated cache folders are intentionally excluded.
